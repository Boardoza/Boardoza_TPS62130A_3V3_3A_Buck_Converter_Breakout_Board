# Boardoza TPS62130A 3A Buck Converter Breakout Board

The **Boardoza TPS62130A Breakout Board** is a compact and high-efficiency **3.3V buck (step-down) DC/DC converter** designed to deliver up to **3A output current** from a wide input voltage range. Based on the **Texas Instruments TPS62130A**, this board integrates advanced DCS-Control™ topology to provide excellent transient response, low output ripple, and high efficiency across load conditions.

With its ultra-low quiescent current and seamless Power Save Mode operation, this breakout board is ideal for **battery-powered systems as well as industrial and embedded applications**. It is perfect for powering microcontrollers, single-board computers, communication modules.

## Key Features

- **Wide Input Range:** Accepts 4V to 17V input, suitable for common DC output.
- **High Output Capability:** Provides up to 3A continuous output current.
- **Fixed 3.3V Output:** Optimized for 3.3V digital systems.
- **High Efficiency Design:** DCS-Control™ topology ensures fast transient response and stable regulation.
- **Ultra-Low Quiescent Current:** Typical 17µA for low-power applications.    
- **Integrated Protections:** Includes short-circuit and thermal protection.

---

## Technical Specifications

**Model:** TPS62130A  
**Manufacturer:** Boardoza  
**Manufacturer IC:** Texas Instruments  
**Device Type:** Synchronous Step-Down (Buck) Converter  
**Topology:** DCS-Control™  
**Input Voltage:** 4V – 17V  
**Output Voltage:** 3.3V (Fixed)  
**Maximum Output Current:** 3A  
**Quiescent Current (IQ):** 17µA (typical)    
**Peak Efficiency:** Up to 95%  
**Typical Efficiency:** 90–94% (VIN = 12V, VOUT = 3.3V, medium load)  
**Operating Temperature:** -40°C to +150°C (IC)  
**Board Dimensions:** 20mm x 40mm
